# API Access 供应商目录

API Access 顶部提供“接入管理”和“免费模型与额度”两个选项卡。前者管理现有密钥、模型和渠道；后者用于发现平台，支持中英文、名称及说明搜索、分类筛选、空结果提示和官网链接。点击“前往接入管理”可返回原有配置界面。

目录提取自 OFM 的 `src/providers/registry.json`，共 76 条，保留源 ID、名称和官网地址。数量是产品入口数，包含同一品牌的不同产品；不表示 76 家独立厂商，也不表示全部永久免费。来源许可见 [OFM MIT](licenses/OFM-MIT.txt)。

- 11 条按源目录标记为免费或免费层，具体模型、额度和资格仍需查官网。
- 3 条为本地服务：Ollama、LM Studio、llama.cpp。无需云账号，但需要自己的硬件并遵守模型许可。
- 62 条免费资格待确认，其中包括源目录的 OAuth 产品；卡片说明对应认证方式，不承诺通用 API Key 或免费调用。

未按推测补充供应商，也未从网页免费聊天功能推断免费 API。目录中的模型系列用于介绍，取自源快照，不保证当前账号权益。官网入口由桌面端在外部浏览器打开，失败时显示可直接访问的链接。
