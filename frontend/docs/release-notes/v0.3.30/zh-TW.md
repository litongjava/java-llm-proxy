## 新增

- 關於軟體，如果您有任何問題或建議，請透過 [聯絡我們](https://qm.qq.com/q/3queDaIG) 或 [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) 提交，我們會盡快處理。
- 同時提供命令列和桌面版的 Agent（Codex、OpenCode、DeepSeek Harness）現在可以分別指定命令列程式路徑和桌面程式路徑。自動偵測失敗時，啟動和重新偵測會使用對應路徑。
- 模型別名可供多個來源共用；相同別名可以分別編輯和刪除，儲存時不會互相覆蓋。

## 優化

- 重新設計側邊欄：導覽更精簡，目前頁面更明確；新手模式和聯絡方式改為一般入口，語言與主題切換合併到同一工具列。
- 調整模型別名列表版面，思考等級和 Fast 標記不再擠動編輯與刪除按鈕。
- Agent 設定頁會保留已選擇的模型。重新整理後模型暫時不在清單中時，不會自動改成第一項，並提示目前選擇已無法使用。
- 應用程式更新進度只顯示目前階段，避免進度說明重複跳動。
- 將「恢復歷史工作階段」改為「同步歷史工作階段」，並說明 ChatGPT 會依 API 隔離工作階段；需要舊工作階段時，可在工作階段管理中同步。

## 修復

- API 接入頁會記住上次選擇的服務供應商分類。
- 儲存模型別名時保留無關的設定變更。
