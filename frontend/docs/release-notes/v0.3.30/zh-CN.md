## 新增

- 关于软件，如果您有任何问题或建议，请通过 [联系我们](https://qm.qq.com/q/3queDaIG) 或 [GitHub Issues](https://github.com/router-for-me/EasyCLIProxyAPI/issues) 提交，我们会尽快处理。
- 同时提供命令行和桌面版的智能体（Codex、OpenCode、DeepSeek Harness）现在可以分别指定命令行程序路径和桌面程序路径。自动检测失败时，启动和重新检测会使用对应路径。
- 模型别名允许被多个来源共用；相同别名可以分别编辑和删除，保存时不会互相覆盖。

## 优化

- 重新设计侧边栏：导航更紧凑，当前页面更明确；新手模式和联系方式改为普通入口，语言与主题切换合并到同一工具栏。
- 调整模型别名列表布局，思考等级和 Fast 标记不再挤动编辑和删除按钮。
- 智能体配置页会保留已选择的模型。刷新后模型暂时不在列表中时，不会自动换成第一项，并提示当前选择已不可用。
- 应用更新进度只显示当前阶段，避免进度说明重复跳动。
- 将“恢复历史会话”改为“同步历史会话”，并说明 ChatGPT 会按 API 隔离会话；需要旧会话时，可在会话管理中同步。

## 修复

- API 接入页会记住上次选择的服务商分类。
- 保存模型别名时保留无关的配置改动。
